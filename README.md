# marine-data-ai-resources

This repository contains a guidance for marine data repositories in the development of AI skills and related documentation.

An AI skill is the instructions you provide to your AI agent on how to use the available tools appropriately. 

Think of it as when someone who doesn't know a thing about your repository and how to access data from it. You give them an introduction of the various ways to find data and access data in your repository. The AI skill is essentially documenting that base knowledge so that any agent can understand how to interact with your repository. 

You can find more information about skills at:
* https://agentskills.io/home
* https://github.com/anthropics/skills
* https://github.com/GoogleCloudPlatform/open-knowledge-format
