# Templates

The [data facility profile template](data-facility-profile-template.md) combines a small required core with interchangeable modules.

When creating a data facility profile:

1. Copy the template into `data-facilities/<short-name>.md`.
2. Complete every **Core** section.
3. Keep only the **Access modules** that apply.
4. Link to official facility documentation instead of copying it.
5. Remove drafting instructions and empty optional sections before review.
6. Record who prepared and reviewed the page and when.

The template is intentionally broader than any single facility. A facility is not expected to offer every access method.
