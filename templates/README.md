# Templates

The [repository page template](repository-page-template.md) combines a small required core with interchangeable modules.

When creating a repository page:

1. Copy the template into `repositories/<repository-name>.md`.
2. Complete every **Core** section.
3. Keep only the **Access modules** that apply.
4. Link to authoritative repository-owned documentation instead of copying it.
5. Remove drafting instructions and empty optional sections before review.
6. Record who prepared and reviewed the page and when.

The template is intentionally broader than any single repository. A repository is not expected to offer every access method.
