# Contributing to the marine-data-ai-resources repository

Thank you for taking the time to consider making a contribution to the repository.

These contribution guidelines are designed to outline the usage of this repository and make it easy for others to contribute.

If at any time you have questions, ask for help.

Your contribution is valuable and the community will be happy to give a hand.

## Contributing to documents in the repository
To propose a change to a document in the repository, please create a fork of the repository, make your changes, and submit a pull request for review. 
This allows better tracking of the changes that have been made. 
Further information about pull requests can be found at https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request-from-a-fork.
