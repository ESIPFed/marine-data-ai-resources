# Marine Data Facility Catalog

This directory contains one self-contained guidance profile for each participating marine data facility. Each profile should help people and agents understand the facility's scope, authoritative role, identifiers, access methods, limitations, and relationships to other facilities.

Create new profiles from the [facility page template](../templates/data-facility-profile-template.md).

## Facility profiles

No facility profiles have been added yet. Initial profiles will be developed and tested as community pilots.

## Profile status

- **Draft:** Incomplete or under active development.
- **Community-contributed:** Useful guidance that has not yet been reviewed by a representative of the described facility.
- **Facility-reviewed:** Reviewed by a named representative of the described facility on the date recorded in the profile.
- **Cluster-tested:** Tested against documented use cases by the ESIP Marine Data Cluster. This status is not a certification or blanket endorsement of the facility or its services.

A profile may be both facility-reviewed and cluster-tested. Status describes the profile and its review history, not the overall quality or maturity of the data facility.
