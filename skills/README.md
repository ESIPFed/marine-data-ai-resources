# Agent Skills

This directory contains reusable workflows maintained by this project. A skill belongs here when it supports work across the project or when no more appropriate facility-owned version exists.

Facility-specific skills maintained by a data facility should normally remain with that facility and be linked from its profile rather than copied here.

## Available skills

| Skill | Purpose | Status |
|---|---|---|
| [`draft-data-facility-profile`](draft-data-facility-profile/SKILL.md) | Guide a contributor through researching, drafting, and reviewing a facility profile | Draft |

Skills use a directory containing a singular `SKILL.md` file. Their instructions and status should be refined through realistic use rather than treated as complete on first publication.
